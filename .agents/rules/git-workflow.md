# Regla Git: "subi todo"

Siempre que el usuario solicite **"subi todo"** (o variantes como *"subí todo"*, *"subir todo"*, *"subir los cambios"*):
- Ejecutar `git add .`
- Realizar commit con un mensaje descriptivo de las tareas completadas.
- **Subir obligatoriamente a la rama `main`** (`git push origin main`).
- En Windows usar `& "C:\Program Files\Git\cmd\git.exe"` si `git` no está en el PATH de la sesión de PowerShell.
